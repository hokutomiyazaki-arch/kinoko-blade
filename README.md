# 菌血闘技 / KINOKO BLADE

横スクロール、きのこが剣で戦う対戦ゲーム。
プレイヤーの操作は **攻撃 / 防御 / 飛び道具 / スペシャル** の4ボタンだけ。移動は自動。
敵は **Lv.1 から始まり、勝つたびに強くなる**。勝利報酬のガチャで使い切りの武器が手に入る。

**▶ 遊ぶ: https://hokutomiyazaki-arch.github.io/kinoko-blade/** （スマホ可・インストール不要）

```
open index.html   # ローカルでも動く。ビルド不要、依存ゼロ
```

---

## ルール

- きのこは常に左右へ自動で歩く。壁か相手にぶつかると反転する。
- 攻撃・防御・飛び道具はそれぞれ**独立したゲージ**が満タンのときだけ発動する。
  3本とも同時に溜まり、画面下に3つ並べて表示する。
- ゲージは **歩いている間しか溜まらない**。行動中・硬直中は3本とも止まる。
  → すべての行動に「次の準備が遅れる」という機会費用がある。
- 攻撃は `振りかぶり → 判定 → 硬直` の3段階。判定は前方 `reach` 以内のみ。
  空振りするとゲージは丸ごと消える。
- 防御中に殴られると:
  - **通常ガード** … ダメージの35%が削りとして通る（上限5）
  - **ジャスト防御** … 防御開始から `parryWindow` 秒以内なら削りゼロ＋相手に0.65秒の硬直
- **飛び道具**は全キャラが持つ。前方へ胞子を撃つ。
  移動が自動＝**避けられない**ので、飛び道具に対する答えは防御しかない。
  これが防御の存在意義になっている。
  - 通常ガード … 削り（35%・上限5）が通り、**防御ゲージが45%戻る**
  - ジャスト防御 … 完全に消滅し、**防御ゲージが75%戻る**
  - 受け切ると次の防御が早く回るので、連射だけで防御を枯らすことはできない
  - 撃ち合った弾同士は相殺する
- **スペシャル武器**はゲージではなく所持数で撃つ。1回使うと消える（手持ち5個まで）。
  勝利報酬のガチャでしか手に入らないので、「どの試合のどの場面で使うか」が選択になる。
- 90秒経過で残りHP割合の高い方が勝ち。

**タイミングの本質**: 振りかぶりがある以上、攻撃ボタンは「当たる瞬間」ではなく
「当たる瞬間の `windup` 秒前」に押す必要がある。相手の接近速度から逆算する。

## 敵のレベル

**Lv.1 から始まる。勝つと+1、負けても下がらない。** ブラウザに保存される。

レベルが変えるのはCPUの中身だけで、キャラの性能表は動かさない。

| | Lv.1 | Lv.10 | Lv.20 |
|---|---|---|---|
| 反応の遅れ | 0.60s | 0.22s | 0.12s |
| 振りかぶりを見てガードする確率 | 20% | 72% | 87% |
| 飛んでくる弾をガードする確率 | 25% | 80% | 92% |
| 飛び道具を撃つ確率 | 15% | 55% | 70% |
| 与ダメージ倍率 | 0.75 | 1.00 | 1.00 |
| 体力 | ×1.00 | ×1.00 | ×1.15 |

**Lv.10 がこれまでのCPUと同じ強さ**。それ以降は反応と体力が伸びる。

内挿は線形ではなく `t = ((lv-1)/9)^0.5`。線形にすると Lv.1〜6 の差が体感できないため
（下の実測がその根拠）。

```bash
node tools/balance-sim.js levels     # Lv.N の敵 vs Lv.10 の敵（同キャラ・各120戦）
```

```
Lv.1     0.5%
Lv.3     3.3%
Lv.5    10.5%
Lv.8    25.2%
Lv.10   48.6%      ← 従来のCPU
Lv.15   72.2%
Lv.20   83.7%
```

## スペシャル武器とガチャ

使い切りの技。**勝ったときだけガチャが回せる**。手持ちは5個まで、1回使うと消える。
CPUは持たない（勝った側への報酬なので非対称でよい）。

| 印 | 名前 | 効果 | 出現率 |
|---|---|---|---|
| 嵐 | 胞子嵐 | 胞子を5発ばら撒く（1発7）。全部ガードするのは難しい | 20% |
| 縛 | 菌糸縛り | 命中で1.6秒硬直（ダメージ4）。止めてから斬るための技 | 17% |
| 断 | 大傘断ち | 間合2倍の大振り28。ガードされても半分（14）は通る | 14% |
| 毒 | 猛毒雲 | 特大の毒雲。10＋猛毒3.0/秒×6秒。長く居座る | 11% |
| 雷 | 落雷菌 | 距離無関係に真上から22。ただしガードには完全に消される | 8% |
| × | はずれ | | 30% |

出現率は `WEAPONS[].weight` と `GACHA_MISS` の比。20000回引いて実測（はずれ 29.9%、
5種すべて出現、レア度の順序どおり）。

**設計**: 一番強い落雷菌は距離を無視して当たるかわりに、ガード一発で完全に消える。
「強い技ほど読まれたときの損が大きい」という本編のルールを、報酬側にも通してある。

## バランス設計の考え方

### 速度は「攻撃力」ではなく「テンポ支配力」

移動が自動なので、**速度は1試合あたりの交錯回数を決める**。
交錯間隔はおおよそ `2 × 壁までの距離 ÷ (自速度 + 相手速度)`。

- 速い → 交錯が増える。相手の攻撃ゲージが溜まりきる前に次の交錯を押しつけられる。
  つまり**速度は相手のゲージを飢えさせる武器**。
- 遅い → 交錯が稀。1回の交錯を必ず決めきらないと負ける。

そこでゲージ秒数を速度と**ゆるく逆相関**させた（エノキ 141/1.1s ↔ ベニテング 53/3.2s）。
完全な逆相関にすると全員が同じ強さになるので、**攻撃・防御・飛び道具の3ゲージを分離**して型を作った。

### 型の分岐

| 型 | 攻/防/飛ゲージ | 勝ち筋 |
|---|---|---|
| エノキ | 1.1 / 0.9 / 2.7 — 全部速い | 手数で押し切る。針で防御を削ってから斬る |
| ベニテング | 3.2 / 2.0 / 2.2 — 弾が主軸 | 毒霧を置いて触らせ、交錯1回を23＋毒で決める |
| マイタケ | 2.8 / **1.05** / 2.6 — 守り特化 | 殴らせて反射する。遠距離は山なり弾で潰す |
| マツタケ | 2.8 / 2.0 / 2.9 — ジャスト特化 | 受付0.24秒でパリィ→攻ゲージ全快→即斬り返し |
| シイタケ | 2.0 / 1.2 / 3.3 — 中庸 | どの択も一応取れる。基準線 |

### 防御ゲージの上限を2.0秒にした理由

飛び道具の答えが防御しかない以上、防御ゲージが2秒を大きく超えるキャラは
「弾を受ける手段がない」＝詰みになる。旧版の 2.6s / 2.4s（ベニテング・マツタケ）は
シミュレータ上で勝率20〜30%まで落ちたので 2.0s に詰めた。
遅さの表現は**ゲージではなく guardTime とジャスト受付**（持続と受付の広さ）に寄せている。

### 画面を広く使うための空間スケール

「画面全体に表示する」ために闘技場の横幅を 640 → 560（壁間 552 → 472）に詰めた。
ただし交錯間隔は `2 × 距離 ÷ (自速度 + 相手速度)` なので、距離だけ縮めると
テンポが変わってバランスが崩れる（実測でエノキが70%まで跳ねた）。
そこで**速度・間合・弾速・ノックバックも同じ 0.855 倍**にし、時間の定数（ゲージ秒数、
振りかぶり、ジャスト受付）は一切触っていない。空間だけの相似縮小なので交錯間隔は不変。

### 籠城対策

防御が完全無敵だとマイタケが不落になる。そこで:
- 通常ガードは35%（上限5）の削りが通る
- ゲージは防御中は溜まらない → マイタケの防御稼働率は上限 `0.90 / (0.90+1.05) ≈ 46%`
- 削り上限5があるので、逆に高火力キャラがガード越しに低HPキャラを溶かすこともできない

## 相性表（CPU総当たり 300戦/組）

`tools/balance-sim.js` で検証した実測値。行=自分、列=相手。**両者 Lv.10 のCPU同士**。
乱数は種を固定してあるので、**同じ数値なら誰が回しても同じ表が出る**。
（スペシャル武器はプレイヤー専用の報酬なので、この対称な表には含めない）

```
             シイタケ  エノキ  ベニテング  マイタケ  マツタケ    平均
シイタケ        56%    52%     52%      52%     29%      46.0%
エノキ          43%    48%     34%      60%     65%      50.2%
ベニテング      51%    67%     54%      23%     66%      51.5%
マイタケ        55%    36%     77%      54%     27%      48.7%
マツタケ        68%    27%     34%      68%     42%      49.2%
```

全体の平均勝率は **46.0% 〜 51.5%** に収束し、かつ三すくみが立っている:

```
エノキ ──65%──▶ マツタケ ──68%──▶ マイタケ ──77%──▶ ベニテング ──67%──▶ エノキ
```

シイタケは全員に 52% 前後で並ぶ（＝基準線）が、マツタケにだけ 29% で負ける。
「強いキャラ」ではなく「刺さる相手が違うキャラ」になっている状態。

### 数値をいじったら

```bash
node tools/balance-sim.js
```

`tools/balance-sim.js` 冒頭の配列は `index.html` の `SPECIES` と同じ値を持つ。
**片方を変えたら必ずもう片方も合わせること**（現状は手動同期。
気になるなら `src/balance.json` に切り出してビルド時に埋め込むのが次の一手）。

シムは `require()` でも読める（`{S, R, fight, table, reseed}` を返す）。
数値を振って勝率を見る調整スクリプトを別に書くとき用。

## 操作

| | 攻撃 | 防御 | 飛び道具 | スペシャル |
|---|---|---|---|---|
| タッチ | 攻 | 防 | 飛 | 特 |
| キーボード | `F` / `←` | `J` / `→` | `K` / `↑` / `space` | `L` / `↓` |

スペシャルは画面下の5枠から使うものを選んでから `特`。手持ちがなければ押せない。

画面は縦横とも端末いっぱいに広がる。闘技場の**横幅（＝壁の間隔）は 560 で固定**し、
高さだけ画面比に合わせて伸ばす。横幅を画面ごとに変えると壁までの距離が変わり、
交錯間隔＝バランスが端末ごとに変わってしまうため。

## 見た目について

### キャラクター

丸い体・こげ茶の太い輪郭・怒り眉・叫び口・頬の赤み、ぽんぽん付きの傘に剣。
**画像ファイルは使っていない**（`drawMushroom()` が canvas に直接描く）。
依存ゼロの単体HTMLという性質を保つためで、色と傘の柄を差し替えるだけで種が増やせる。

| | 体色 | 傘 | 剣 |
|---|---|---|---|
| シイタケ | 水色 | 水玉 `spot` | 藤色 |
| エノキ | 生成り | 無地 `plain` | 灰白 |
| ベニテングタケ | 桃 | 水玉 `spot` | 桃 |
| マイタケ | 若草 | つば付き `visor` | 若草 |
| マツタケ | 藤 | 縦縞 `stripe` | 藤 |

HPが0になった側は**撃沈の姿勢**（×目・傘が裂けて放射状に広がる）に切り替わり、
1.1秒その姿を見せてから結果画面へ移る。時間切れの決着では0.26秒しか待たない。

### 音

**音声ファイルは1つも持たない。** Web Audio のオシレータとノイズからその場で合成している。
`index.html` 1枚をURLで渡せば遊べる、という配布の形を崩さないため。

- 効果音は20種。斬り・命中・ガード・ジャスト防御・撃沈・勝敗・スペシャル・ガチャなど
- **飛び道具は軌道ごとに鳴りを変えた**（`dart` は短い高音、`mist` は低く長い擦れ、
  `lob` は上がる音、`wave` は2つの正弦をずらしたうねり）。画面を見ていなくても
  何が飛んできたか分かる
- ゲージが満タンになった瞬間だけ合図が鳴る。攻660Hz / 防880Hz / 飛1100Hz と
  高さを変えてあるので、3本のどれが溜まったか音で分かる
- BGMは**都節音階**（0,1,5,7,8半音）の32ステップ・ループを先読みスケジューラで生成。
  選択画面=旋律と低音のみ / 戦闘中=太鼓が入る / 残り15秒=速くなる
- 右上の ♪ でオン・オフ。設定は `localStorage` に残る
- 自動再生規制があるので `AudioContext` は最初のタップ／キー入力まで作らない。
  タブが隠れたら `suspend()` する

出力レベルは `OfflineAudioContext` で書き出して実測した（各音 peak 0.07〜0.30、
同時に7音＋BGMを鳴らした最悪ケースでも 0.67 でクリップしない）。

### 画面の配色

配色は**胞子紋（spore print）** から取った。きのこの傘を紙に伏せて一晩置くと
胞子が落ちて放射状の模様ができる。その色は分類の手がかりで、
紫黒・クリーム・錆褐色・桃色といった実在の分類名がある。

- `--ink #1E1B24` 紫黒胞子 → 背景
- `--cream #EDE4CC` クリーム胞子 → 文字
- `--rust #B06A3B` 錆褐色胞子 → 攻撃
- `--ochre #C6A24A` 黄土色胞子 → 飛び道具
- `--pink #D08A92` 桃色胞子 → 被弾
- `--moss #7C8F4E` → 防御

ゲージは傘を裏から見たヒダ（gill）の放射状に描いている。これが画面の署名要素。
